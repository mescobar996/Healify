Cómo funciona

Tres pasos, todo en tu máquina. Nada sale a ningún lado.

1

Corré tu suite normal

Un test falla porque un selector ya no existe en el DOM.

2

Healify analiza el selector roto

Local, sin red. Propone una alternativa más estable, con un puntaje de confianza.

3

Generá el reporte y aplicá el fix

healify-report.html con cada caso: selector viejo, sugerencia y confianza. npx @healify/cli fix aplica los de mayor confianza directo en tu código.

Paquetes

Todos @healify/*, todos npm, todos locales.

@healify/test-runner

Reporter para Playwright, genera healify-report.html al final.

npm i -D @healify/test-runner
@healify/cypress-plugin

Plugin para Cypress. Mismo reporte.

npm i -D @healify/cypress-plugin
@healify/selenium-plugin

Wrapper de WebDriver, cura selectores en vivo.

npm i -D @healify/selenium-plugin
@healify/webdriverio-plugin

Wrapper de WebdriverIO, cura en vivo.

npm i -D @healify/webdriverio-plugin
@healify/cli

Terminal: doctor, init, fix, history.

npm i -D @healify/cli
